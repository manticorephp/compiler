PHP in. Native binary out.

Manticore compiles PHP 8.5+ to standalone arm64 and x86_64 binaries through LLVM. No interpreter, no php.ini, no extension loader. The compiler is written in PHP and compiles itself to a byte-identical fixpoint.

manticore compile app.php -o app && ./app
Install Read the docs

Same bytes as Zend

The Zend interpreter is the oracle. If php runs a program, the native binary prints the same output. Every plain-runnable test case is diffed against it.

Install

curl -fsSL https://raw.githubusercontent.com/manticorephp/compiler/main/install.sh | bash
export PATH="$HOME/.manticore/bin:$PATH"
manticore version
