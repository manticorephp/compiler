## 4. Traps that cost real time here

- **A pipe eats the exit code.** `bin/build … | tail` reported success on a failed
  preflight. Redirect to a file.
- **xdebug poisons the difftest oracle** (stack-trace decoration). Run php with
  `-d xdebug.mode=off`; a ready shim is in the session scratchpad.
- **A probe binary outside the checkout cannot find `lib/`** (`bin/../lib`) and
  dies on stdlib paths — it looks exactly like a codegen regression. Put the probe
  in `bin/`.
- **A gen-2 binary needs `MANTICORE_PRELUDE` exported** or it fails with
  "prelude: cannot read var_export.php" long before any real bug.
- **`grep "^define "` undercounts streamed IR** — a spilled body used to be
  appended without a trailing newline, so the next one began as `}define …`.
  Fixed in `6376f41`, but match the full mangled name, and note `foo$mono$1`
  collapses to `foo` if the pattern stops at `$`.
- **`gdb` is not in `manticore-toolchain:arm64`** and `apt-get` fails there.
  `error_log` checkpoints beat a debugger — stderr survives a SIGSEGV, stdout
  does not.
- **`run_tests.sh` passes env with `-e`**, so a hypothesis can be tested in the
  container without editing the tracked script.

## 5. Two method rules worth more than the bugs

- **A test that deletes the suspect cannot tell identity from quantity.** Removing
  the `version` command "proved" it was special; removing a *different* command
  fixed it too — it was the count all along. Always delete a control.
- **Measure the flag, not the concept.** The ThinLTO cache was benchmarked for its
  incremental value (≈ zero), and then defaulted off — without ever measuring the
  cold case, where it halves the link. Two different questions, one answer applied
  to both.
